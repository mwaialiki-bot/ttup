Privacy Policy

YouTube Uploader is a personal application used by its owner to upload video files to their own YouTube channel.

Information Access

The application uses Google OAuth 2.0 to authorize access to the owner's YouTube account. It uses the YouTube Data API for video uploads and related operations.

Data Usage

Information accessed through Google APIs is used only to provide the application's video upload functionality.

The application does not sell Google user data or share it with third parties for advertising.

Data Storage and Security

OAuth credentials and authorization tokens are stored securely by the application owner. Access is restricted to the application owner.

Data Retention and Deletion

The application owner can revoke authorization through their Google Account security settings. Locally stored authorization tokens can also be deleted by the owner.

Contact

For privacy-related questions, please contact the application developer using the developer contact email listed on the OAuth consent screen.
